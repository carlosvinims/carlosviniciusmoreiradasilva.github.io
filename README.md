# Portfólio — Carlos Vinicius

Meu portfólio pessoal, onde reúno quem eu sou, meus projetos, tecnologias, formação e certificados.

Feito com HTML, CSS e JavaScript puros, sem frameworks e sem etapa de build. O visual é inspirado no template Notio, da StyleUI.

## O que tem no site
- Apresentação e resumo do perfil
- Sobre mim
- Projetos (com filtro por categoria)
- Tecnologias e habilidades
- Formação e certificados
- Contato

## Estrutura
```
index.html
assets/
├── css/styles.css
└── js/main.js
```

## Como ver no computador
Abra o arquivo `index.html` no navegador.

## Publicação
O site é estático e roda no GitHub Pages. Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
